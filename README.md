# BEARTS

Modern art website and order system for an artist brand.

Features:
- Landing page with art gallery
- Commission request form
- Order form
- Express backend API
- JSON data store for products and orders

Quick start:

Backend:
cd backend
npm install
npm run dev

Frontend:
cd frontend
npm install
npm run dev

Open the frontend at http://localhost:3000

API routes:
- GET /api/products
- POST /api/orders
- POST /api/commission
